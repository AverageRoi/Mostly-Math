MOSTLY MATH : NETLIFY QUICK START

1. Unzip and place the files/folders inside your new GitHub repository root.
2. Import that repository into Netlify.
3. Leave Netlify's build settings to netlify.toml. Do not add GitHub Actions.
4. Once deployed, a commit to the repository automatically triggers a new build.
5. Read README.md for writing new notes and running locally.

THEME NOTE: Hugo Stack v4 is a pinned Hugo Module dependency. It downloads
on the first build; it is not vendored into this ZIP.
